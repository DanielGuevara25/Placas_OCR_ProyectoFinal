# Resultados

- `training/`: tres experimentos originales con configuraciones, métricas y checkpoints.
- `evaluation/`: evidencia y documentación de evaluación del detector y OCR.
- `overfitting/`: métricas por época y curvas train/val.
- `ocr/`: salida local de evaluación OCR, excluida de Git.
- `predictions/`: fotografías y salidas locales, excluidas de Git.
- `runs/`: corridas auxiliares locales, excluidas de Git.
- `figures/`, `metrics/`, `reports/`: reservadas para los materiales finales de entrega.

Las rutas absolutas dentro de los registros históricos se conservan como evidencia
del contexto original. La reorganización no representa una nueva corrida experimental.
